# Game Client Portfolio

Unity와 Unreal Engine 기반으로 작업한 클라이언트 / 런타임 시스템 포트폴리오 저장소입니다.

이 저장소는 하나의 완성 프로젝트를 그대로 공개한 형태가 아니라,  
외부에 공유 가능한 범위의 핵심 시스템 코드와 구조를 정리한 **포트폴리오용 코드 샘플 모음**입니다.

## 소개

이 저장소는 다음과 같은 역량을 보여주기 위한 목적으로 구성했습니다.

- Unity와 Unreal Engine 양쪽 환경에서의 클라이언트 시스템 구현
- 캐릭터, 애니메이션, 이벤트, 흐름 제어, 렌더링 등 런타임 시스템 설계
- 실무형 코드 구조, 책임 분리, 확장 가능한 아키텍처 구성
- 프로젝트별 핵심 기능을 포트폴리오 형태로 정리하는 방식

## 저장소 구성

```text
game-client-portfolio/
├─ Unity/
└─ Unreal/
   ├─ UE5_AI Companion/    # 실시간 AI 캐릭터 컴패니언
   ├─ UE5_AbilitySystem/   # 커스텀 어빌리티 시스템
   └─ UE5_ContentSystem/   # 아웃게임 컨텐츠 프레임워크
```

### Unity

Unity 쪽 포트폴리오는 3D 캐릭터 기반 프로젝트를 위한 코어 프레임워크 중심으로 구성했습니다.

주요 내용:

- 캐릭터 생성 / 장착 / 해제 구조
- 상하체 분리 애니메이션 오버레이
- Event Bus, AppFlow, StepFlow 기반 흐름 제어
- 입력 추상화 구조
- URP Renderer Feature 기반 커스텀 렌더링

바로가기:
- [Unity 포트폴리오 보기](./Unity/)

### Unreal

Unreal 쪽 포트폴리오는 세 개의 프로젝트로 구성했습니다.

**AI 캐릭터 컴패니언** — 실시간 AI 상호작용 시스템

- 실시간 음성 상호작용 흐름
- STT (Speech-to-Text, 음성 인식), TTS (Text-to-Speech, 음성 합성), 립싱크 연동
- AI 응답 처리 및 음성 파이프라인 제어
- 캐릭터 커스터마이징 및 외형 처리
- 런타임 시스템 구조와 서비스 연동 방식

**커스텀 어빌리티 시스템** — 어빌리티 · 스탯 · 상태효과와 네트워크 동기화

- GameplayTag 기반 어빌리티 / 스탯 / 상태효과
- 모디파이어 스택 스탯, 서버 시간 기준 효과 수명 처리
- 이벤트 재생 + 상태 해시 기반 네트워크 동기화
- 시간 소스 추상화로 로컬 / 서버 / 테스트 교체

**아웃게임 컨텐츠 시스템** — 반복 컨텐츠를 공통 프레임워크로 찍어내는 구조

- 도메인별 모델이 데이터를 단독 소유하고 변경을 통지 (`OnDataChanged`)
- 요청 / 응답 / 노티 · 캐시 정책 · UI 통지를 프레임워크가 공통 처리
- 파생 모델 자동 스캔 · 등록 — 컨텐츠 추가 시 프레임워크 코드 무수정
- 태그 기반 이벤트 채널로 도메인 간 종속성 제거

## 이 저장소의 목적

이 저장소는 다음을 보여주기 위한 포트폴리오용 저장소입니다.

- 특정 엔진 하나에 한정되지 않는 클라이언트 시스템 구현 경험
- Unity / Unreal 각각의 환경에 맞춘 구조 설계 방식
- 게임 클라이언트에서 자주 다루는 런타임 문제를 어떻게 구조적으로 해결했는지
- 기능 구현뿐 아니라 유지보수성과 확장성을 고려한 코드 작성 방식

## 참고 사항

- 이 저장소는 전체 실행 프로젝트 재현 목적이 아닙니다.
- 일부 샘플은 프로젝트 종속 리소스, 에셋, 플러그인, 설정 파일이 제외된 상태입니다.
- 공개 범위에 포함할 수 없는 사내 리소스, 상용 에셋, 인증 정보, 서드파티 원본 코드는 포함하지 않습니다.
- 각 하위 폴더의 README에서 프로젝트별 상세 설명을 확인할 수 있습니다.
