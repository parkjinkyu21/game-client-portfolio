# UE5 AI Companion 포트폴리오 코드 샘플

이 저장소는 Unreal Engine 5 기반 AI 캐릭터 컴패니언 프로젝트에서 제가 직접 설계하고 구현한 핵심 소스 코드를 정리한 포트폴리오용 공개 저장소입니다.

전체 프로젝트를 그대로 공개한 저장소는 아니며, 외부에 공유 가능한 범위의 핵심 시스템 코드만 선별하여 포함했습니다.

## 저장소 소개

프로젝트는 실시간 AI 캐릭터 상호작용을 목표로 구성되었으며, 다음과 같은 흐름을 포함합니다.

- 음성 입력 처리
- STT (Speech-to-Text, 음성 인식)
- AI 응답 처리
- TTS (Text-to-Speech, 음성 합성)
- 립싱크 및 표정 출력
- 캐릭터 커스터마이징 시스템

이 저장소는 위 기능들 중 클라이언트 측 핵심 구현 로직과 시스템 구조를 보여주기 위한 코드 샘플에 초점을 두고 있습니다.

## 저장소에 포함된 내용

- 핵심 C++ 시스템 / 게임플레이 코드
- AI 음성 파이프라인 제어 로직
- TTS / STT / 스트리밍 연동 로직
- 립싱크 / 표정 애니메이션 관련 런타임 처리 로직
- 캐릭터 장비 / 커스터마이징 관련 코드
- 시스템 구조 및 설계 방향을 보여주는 구현 샘플

## 저장소에 포함되지 않은 내용

- 전체 Unreal 프로젝트 파일
- 사내/상용 에셋 및 콘텐츠 리소스
- Blueprint 에셋 및 Content 리소스
- 전체 빌드 설정 파일
- 내부 서버 코드
- 외부 인증키 / 토큰 / 시크릿 정보
- 제가 소유하지 않은 서드파티 바이너리 및 플러그인 원본 코드

## 참고 사항

이 저장소는 clone 후 바로 실행하거나 빌드하는 목적의 저장소가 아닙니다.

일부 코드는 프로젝트 내부의 에셋, Blueprint 클래스, Content 경로, 외부 플러그인 및 라이브러리를 전제로 작성되어 있으며, 해당 요소들은 공개 범위에서 제외되어 있습니다.

이 저장소의 목적은 전체 프로젝트 재현이 아니라, 실제 프로젝트에서 사용한 구현 방식, 시스템 구조, 코드 스타일을 포트폴리오 형태로 보여주는 것입니다.

## 구현한 내용

이 저장소에 포함된 소스 코드는 모두 제가 직접 설계하고 구현한 코드입니다.

공개된 코드에서는 주로 다음 영역을 확인할 수 있습니다.

- 클라이언트 실시간 음성 상호작용 흐름 제어
- VAD (Voice Activity Detection, 음성 활동 감지), STT (Speech-to-Text, 음성 인식), AI 응답 처리, TTS (Text-to-Speech, 음성 합성), Facial 출력 흐름 오케스트레이션
- 복수 음성 프로바이더 연동을 위한 런타임 분기 및 제어 구조
- 외부 AI 연동 서비스의 인증 및 연결 흐름 처리
- 립싱크 / 표정 데이터의 런타임 처리 로직
- 슬롯 기반 장비 시스템 및 캐릭터 커스터마이징 로직
- 외형 변형을 위한 Morph Target 계산 로직
- 모듈화와 확장성을 고려한 Unreal C++ 시스템 구현

## 기술 포인트

### 1. 실시간 음성 파이프라인

코드에는 실시간 대화형 캐릭터를 위한 전체 음성 흐름 제어가 포함되어 있습니다.

- 사용자 음성 입력
- 음성 활동 감지
- 음성 인식 처리
- AI 응답 요청 / 수신
- 음성 합성 재생
- 립싱크 및 표정 출력

단순 기능 단위 구현이 아니라, 실제 런타임 흐름에서 각 단계를 연결하고 제어하는 구조에 초점을 두었습니다.

### 2. 복수 음성 / AI 서비스 연동 구조

프로젝트는 플랫폼 및 상황에 따라 여러 외부 서비스를 연동할 수 있도록 구성되었습니다.

공개된 코드에서는 다음과 같은 구조를 볼 수 있습니다.

- 프로바이더 선택 및 분기 처리
- 요청 / 응답 흐름 관리
- 스트리밍 기반 처리 구조
- 재생 시스템과의 연결
- 외부 서비스 전환 및 확장을 고려한 런타임 제어 방식

### 3. 립싱크 / 표정 런타임 처리

저장소에는 캐릭터의 음성 출력과 표정 반응을 연결하기 위한 런타임 처리 코드가 포함되어 있습니다.

- 비짐(Viseme) 및 표정 데이터 처리
- 음성 또는 AI 응답 결과와 캐릭터 페이셜 출력의 연결
- Audio2Face 계열 워크플로우를 포함한 확장 가능한 구조

### 4. 캐릭터 커스터마이징 시스템

공개 코드에는 캐릭터 외형 변경과 관련된 로직도 포함되어 있습니다.

- 슬롯 기반 장비 처리
- 장착 상태에 따른 외형 갱신
- Morph Target 관련 계산
- 캐릭터 파츠 간 런타임 연동

유지보수성과 기능 확장성을 고려한 구조로 구현했습니다.

## 설계 방향

코드는 런타임 제어와 기능 확장을 고려한 시스템 중심 구조를 지향합니다.

주요 방향은 다음과 같습니다.

- 기능 / 시스템 단위 책임 분리
- 외부 서비스 의존 기능의 안정적인 런타임 제어
- AI, 음성, 캐릭터 관련 시스템의 모듈화
- 기존 구조를 크게 훼손하지 않고 외부 연동을 교체 / 확장할 수 있는 설계

## 사용된 외부 요소

원 프로젝트에서는 다음과 같은 외부 플러그인 및 라이브러리를 함께 사용했습니다.

- RuntimeAudioImporter
- RuntimeMetaHumanLipSync
- CriWare
- whisper.cpp
- NVIDIA Audio2Face 계열 워크플로우
- 외부 STT / TTS / AI 서비스 연동 요소

단, 본 저장소에는 별도 라이선스가 필요한 서드파티 바이너리 및 플러그인 원본 코드는 포함하지 않습니다.

서드파티 구성 요소 사용 시에는 각 라이선스 조건을 별도로 확인해야 합니다.

## 로그 및 디버깅 관련

일부 코드에는 기능 연동 및 디버깅 과정에서 사용한 상세 로그가 포함되어 있을 수 있습니다.

운영 환경에서는 요청 / 응답 전문이나 상세 상태 로그를 그대로 사용하기보다, 보안 및 운영 정책에 맞게 축소, 마스킹, 정리하는 것이 적절합니다.

## 이 저장소를 공개한 목적

이 저장소는 다음 내용을 보여주기 위한 포트폴리오용 코드 샘플 저장소입니다.

- Unreal Engine에서의 클라이언트 시스템 설계 방식
- 실시간 외부 서비스 연동 기능의 구조화 방식
- AI, 음성, 캐릭터 시스템을 하나의 런타임 파이프라인으로 통합하는 방식
- 모듈화, 유지보수성, 확장성을 고려한 구현 스타일
